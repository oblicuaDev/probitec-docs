# Gestión de diferencias

Vista central para trabajar todas las diferencias abiertas, de cualquier conteo.

- **Filtros**: Todos, Faltantes, Sobrantes, Pendientes, Justificadas, Ajustadas.
- **Filtro por rango de fechas**, para acotar el análisis a un periodo.
- Cada diferencia muestra producto, tipo, cantidad, documento de soporte (si ya tiene uno) y estado.

## Tres caminos para resolver una diferencia

1. **"Justificar"** → abre el mismo flujo de vincular un documento que en [Validación documental](/docs/plataforma-web/validacion-documental).
2. **"Justificar con traslado"** → vincula la diferencia a un traslado entre bodegas ya registrado en [Traslados entre bodegas](/docs/plataforma-web/traslados-entre-bodegas) (Siigo no soporta esto, por eso se registra aparte). Queda marcada como **Trasladada**.
3. **"Ajuste forzado"** → lleva a [Ajustes de inventario](/docs/plataforma-web/ajustes-de-inventario) para registrar un ajuste manual, como último recurso, cuando no hay documento ni traslado que la explique.

Una diferencia ya resuelta (Justificada o Ajustada) se muestra como **"Resuelta"** y no tiene más acciones disponibles.
