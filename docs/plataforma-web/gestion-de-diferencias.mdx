# Gestión de diferencias

Vista central del **Conciliador** para trabajar las diferencias de los conteos que envía Bodega.

- **Filtros**: Todos, Faltantes, Sobrantes, Sin justificar, Justificadas, Trasladadas, Ajustadas, Omitidas.
- **Filtro por rango de fechas**, para acotar el análisis a un periodo.
- Cada diferencia muestra producto, tipo (faltante o sobrante), cantidad en unidades, documento sugerido (si lo hay) y estado.

<Captura web src="/img/plataforma-web/05-gestion-de-diferencias.png" alt="Lista de diferencias con sus acciones" pie="Gestión de diferencias" />

## Cómo se calcula una diferencia

Al llegar un conteo, el servidor lo compara automáticamente:

- **Esperado**: el último conteo cerrado de esa bodega o, si aún no hay, su [inventario inicial](/docs/plataforma-web/inventario-inicial).
- **Encontrado**: las etiquetas leídas convertidas a unidades (empaques y [unidades de agrupación](/docs/plataforma-web/unidades-de-agrupacion)).
- Se comparan los productos leídos y todos los productos **rotulados con RFID** que deberían estar en la bodega.

## Cómo resolver una diferencia

- **"Cruce automático"** → vincula de una vez las diferencias que cuadran con facturas y notas crédito sincronizadas de Siigo.
- **"Vincular sugerido"** / **"Justificar"** → la deja **Justificada** con un documento soporte.
- **"Justificar con traslado"** → la deja **Trasladada** con un traslado registrado en [Traslados entre bodegas](/docs/plataforma-web/traslados-entre-bodegas).
- **"Corregir cantidad"** → corrige lo contado (por ejemplo, apareció una caja escondida), con comentario obligatorio.
- **"Omitir"** → retira el producto del conteo (al cerrar se conserva lo esperado), con comentario obligatorio.
- **"Sin soporte"** → no hay documento ni traslado que la explique: queda **No justificada**, con comentario obligatorio. El Supervisor la resuelve con un [ajuste de inventario](/docs/plataforma-web/ajustes-de-inventario).

<Captura web src="/img/plataforma-web/06-diferencia-sin-soporte.png" alt="Ventana para marcar una diferencia sin soporte" pie="«Sin soporte» pide un comentario obligatorio" />

Todas las acciones quedan en la auditoría con su comentario. Mientras quede alguna diferencia **Pendiente**, el conteo no se puede [cerrar](/docs/plataforma-web/cierre-de-inventario).
