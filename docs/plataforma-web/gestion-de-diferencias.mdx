# Gestión de diferencias

Vista central del **Conciliador** para trabajar las diferencias de los conteos que envía Bodega.

## Trabajar un conteo hasta dejarlo listo para el cierre

1. Arriba, en **Conteo**, elige el conteo que vas a conciliar. Por defecto aparece el conteo abierto más antiguo, porque los conteos de una bodega se cierran en orden. También puedes ver **Todos los conteos**.
   - Con el selector de **bodega** (a la izquierda) la lista de conteos se limita a esa bodega, y **«Todos los conteos de esta bodega»** muestra solo sus diferencias. Al ver todos los conteos, cada diferencia indica de qué bodega es.
2. La barra muestra el avance: **«N de M diferencias resueltas · X pendientes»**. El botón **«Ver solo pendientes»** deja en la lista únicamente las que faltan.
3. Resuelve cada diferencia con una de las acciones de abajo.
4. Cuando no queda ninguna **Pendiente**, la barra se pone en verde y se activa **«Ir a cierre de este conteo»**, que abre el [cierre](/docs/plataforma-web/cierre-de-inventario) con ese conteo ya seleccionado.

:::note ¿Hay que justificar todo?
No es necesario que todo quede **Justificado**. Para cerrar basta con que ninguna diferencia esté **Pendiente**: también cuentan como resueltas las **Trasladadas**, **Omitidas**, **Ajustadas** y las marcadas **Sin soporte** (No justificadas). Estas últimas las corrige el Supervisor con un [ajuste de inventario](/docs/plataforma-web/ajustes-de-inventario).
:::

El Conciliador ve el botón como **«Listo para cierre (supervisor)»**: el cierre lo ejecuta un Supervisor o Administrador.

## Filtros y lista

- **Filtros**: Todos, Pendientes, Faltantes, Sobrantes, Sin justificar, Justificadas, Trasladadas, Ajustadas, Omitidas.
- **Filtro por rango de fechas**, para acotar el análisis a un periodo.
- Cada diferencia muestra producto, tipo (faltante o sobrante), cantidad en unidades, documento sugerido (si lo hay) y estado.

## Cómo se calcula una diferencia

Al llegar un conteo, el servidor lo compara automáticamente:

- **Esperado**: el último conteo cerrado de esa bodega o, si aún no hay, su [inventario inicial](/docs/plataforma-web/inventario-inicial).
- **Encontrado**: las etiquetas leídas convertidas a unidades (empaques y [unidades de agrupación](/docs/plataforma-web/unidades-de-agrupacion)).
- Se comparan los productos leídos y todos los productos **rotulados con RFID** que deberían estar en la bodega.

## Cómo resolver una diferencia

- **"Cruce automático"** → vincula de una vez las diferencias que cuadran con los movimientos de inventario de esa bodega: facturas (restan), notas crédito y compras (suman) y ajustes de inventario sincronizados de Siigo, más las [notas de ensamble](/docs/plataforma-web/notas-de-ensamble) registradas en Oblicua.
- **"Vincular sugerido"** / **"Justificar"** → la deja **Justificada** con un documento soporte.
- **"Justificar con traslado"** → la deja **Trasladada** con un traslado registrado en [Traslados entre bodegas](/docs/plataforma-web/traslados-entre-bodegas).
- **"Corregir cantidad"** → corrige lo contado (por ejemplo, apareció una caja escondida), con comentario obligatorio.
- **"Omitir"** → retira el producto del conteo (al cerrar se conserva lo esperado), con comentario obligatorio.
- **"Sin soporte"** → no hay documento ni traslado que la explique: queda **No justificada**, con comentario obligatorio. El Supervisor la resuelve con un [ajuste de inventario](/docs/plataforma-web/ajustes-de-inventario).

<Captura web src="/img/plataforma-web/06-diferencia-sin-soporte.png" alt="Ventana para marcar una diferencia sin soporte" pie="«Sin soporte» pide un comentario obligatorio" />

Todas las acciones quedan en la auditoría con su comentario. Mientras quede alguna diferencia **Pendiente**, el conteo no se puede [cerrar](/docs/plataforma-web/cierre-de-inventario).
