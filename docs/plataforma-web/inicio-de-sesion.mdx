# Inicio de sesión

Pantalla de acceso a la consola web, para todos los roles (Administrador, Supervisor, Conciliador, Bodega y Auditor) — ver [Roles y permisos](/docs/roles-y-permisos).

- **Usuario** (correo) y **Contraseña**.
- **Recordar sesión** y enlace de **"Recuperar contraseña"**.
- Si las credenciales son incorrectas, aparece un mensaje de error debajo del formulario.

<Captura web src="/img/plataforma-web/01-inicio-de-sesion.png" alt="Pantalla de inicio de sesión de la plataforma web" pie="Inicio de sesión" />

Al ingresar, se entra directo al [Dashboard](/docs/plataforma-web/dashboard).
