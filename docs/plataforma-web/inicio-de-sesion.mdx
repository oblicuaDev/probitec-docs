# Inicio de sesión

Pantalla de acceso a la consola web, pensada para un administrador, supervisor o auditor.

- **Usuario** (correo) y **Contraseña**.
- **Recordar sesión** y enlace de **"Recuperar contraseña"**.
- Al pie se indica el estado del servidor y la versión.
- Si las credenciales son incorrectas, aparece un mensaje de error debajo del formulario.

Al ingresar, se entra directo al [Dashboard](/docs/plataforma-web/dashboard).
