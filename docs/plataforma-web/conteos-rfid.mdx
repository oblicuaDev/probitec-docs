# Conteos RFID

Listado completo de los conteos recibidos desde la app móvil.

<Captura web src="/img/plataforma-web/03-conteos-rfid.png" alt="Listado de conteos RFID" pie="Conteos RFID" />


- **Buscador**: por ID de conteo, bodega o usuario.
- **Filtro por estado**: Todos, Pendiente, Conciliado, Con diferencias, Cerrado.
- **Filtro por rango de fechas**: limita el listado a un periodo específico, para no mezclar indicadores de meses distintos.
- La tabla muestra, por conteo: fecha, bodega, usuario, unidades esperadas/encontradas, diferencias, estado y tiempo que tomó.
- El botón **"Ver"** de cada fila abre el [Detalle del conteo](/docs/plataforma-web/detalle-del-conteo).

:::note
Los botones "Excel" y "PDF" de la barra superior son de exportación y aún no están conectados a una descarga real.
:::
