# Historial de inventarios

Registro completo de todos los conteos, cerrados o no, con su estado final.

Para cada conteo se ve: ID, fecha, bodega, usuario, productos esperados, tiempo, porcentaje conciliado, diferencias, ajustes y estado.

:::note
Los selectores de Fecha / Bodega / Usuario / Estado y el botón "Exportar todo" de esta pantalla son controles visuales; todavía no filtran ni exportan datos reales. El filtrado real por fecha ya funciona en [Conteos RFID](/docs/plataforma-web/conteos-rfid) y en [Gestión de diferencias](/docs/plataforma-web/gestion-de-diferencias).
:::
