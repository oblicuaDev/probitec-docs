# Validación documental

Antes de forzar un ajuste, siempre conviene revisar si una diferencia tiene explicación en un documento real del ERP: una factura de venta, una nota crédito o un traslado no registrado a tiempo.

## Documentos disponibles

Lista los documentos de Siigo ya sincronizados. El botón **"Sincronizar con Siigo"** trae los más recientes (facturas, notas crédito, compras, ajustes de inventario y catálogo de productos) directamente desde Siigo; ver [Sincronización](/docs/plataforma-web/sincronizacion). Las [notas de ensamble](/docs/plataforma-web/notas-de-ensamble) registradas en Oblicua también aparecen aquí como documentos.

## Vincular un documento a una diferencia

1. En la tabla de diferencias, pulsar **"Vincular documento"** sobre la diferencia a resolver.
2. Elegir el documento correspondiente en la ventana emergente.
3. La diferencia queda marcada como **Justificada** y desaparece de las pendientes.

Si un documento tiene enlace (ícono ↗), se puede abrir directamente en Siigo para verificarlo.

## Resumen

Contadores de diferencias **Soportadas documentalmente**, **Ajustadas** y **Pendientes de validación**, para saber de un vistazo cuánto trabajo falta.

Cuando una diferencia no tiene ningún documento que la explique, el paso siguiente es un [Ajuste de inventario](/docs/plataforma-web/ajustes-de-inventario) desde [Gestión de diferencias](/docs/plataforma-web/gestion-de-diferencias).
