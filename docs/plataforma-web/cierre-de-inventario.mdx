# Cierre de inventario

Último paso del proceso: bloquea definitivamente un conteo.

## Qué muestra

- Código y bodega del conteo abierto más reciente.
- Resumen: coincidencias, diferencias con conteo, ajustes realizados y justificaciones documentales.
- Responsable, fecha y hora del cierre.
- Si todavía quedan diferencias sin resolver, lo advierte explícitamente (puede cerrarse igual; quedarán registradas como diferencias sin resolver).

## Cerrar

Al pulsar **"Cerrar inventario definitivamente"**, se pide confirmación una segunda vez antes de aplicar el cierre.

:::caution Acción irreversible
Una vez cerrado, el inventario **no puede modificarse nuevamente** y la acción queda registrada en la auditoría.
:::

Tras confirmar, se redirige a [Historial de inventarios](/docs/plataforma-web/historial-de-inventarios).

Si no hay ningún inventario abierto por cerrar, la pantalla lo indica y ofrece ir directo al historial.
