# Conciliación automática

El sistema compara, producto por producto, lo que **se esperaba** encontrar contra lo que **realmente se leyó** por RFID, y genera automáticamente la lista de diferencias.

## Qué muestra

- Resumen: **Coincidencias**, **Faltantes**, **Sobrantes**, **Total de diferencias**.
- **Porcentaje conciliado**: qué proporción del inventario ya cuadra sin diferencias.
- Tabla de análisis por producto: código, cantidad, tipo (Faltante/Sobrante), impacto (Alto/Medio/Bajo) y estado de conciliación.

## Siguiente paso

El botón **"Validar documentalmente →"** lleva a [Validación documental](/docs/plataforma-web/validacion-documental), donde cada diferencia se intenta explicar con un documento real de Siigo antes de pensar en un ajuste forzado.
