# Unidades de agrupación

Una unidad de agrupación es un **código propio que no existe en Siigo** y que representa varias unidades de productos que sí existen. Se usa para rotular las **cajas**: la caja lleva la etiqueta de la agrupación y cada unidad suelta lleva la etiqueta del producto.

> Ejemplo: la caja **AG-22753261001** no existe en Siigo, pero contiene **6 unidades** del producto **22753261001** (POWER PROTECT ULTRA 1LT). Al contar, cada etiqueta de esa caja suma **6 unidades**; cada etiqueta del producto suelto suma **1**.

Está en **Configuración → Unidades de agrupación**. Las crea o edita un **Supervisor** o **Administrador**.

## Las agrupaciones de Probitec

Cada producto de las listas de etiquetas que trae **más de una unidad por empaque** tiene su agrupación, con el código **`AG-` + código de Siigo** y la descripción **«Empaque xN · producto»**. Son 514.

Sus etiquetas se imprimen con el **prefijo EPC** de la agrupación (columna «Prefijo EPC», por ejemplo `25825A…`) + «A» + serial.

:::important
Etiqueta de producto = 1 unidad
Desde octubre de 2026 la etiqueta de un **producto** cuenta siempre **1 unidad**. Para contar una caja completa se usa la etiqueta de su **agrupación**. Si una caja tiene pegada una etiqueta de producto, cuenta solo 1: hay que reemplazarla por la de la agrupación.
:::

## Crear una

1. Pulsa **"Nueva"**.
2. Escribe el **código** (no puede ser un código que ya exista en Siigo) y una **descripción**.
3. Agrega el contenido: el **código de Siigo** de cada producto y cuántas **unidades** trae. Una agrupación puede tener **uno o varios productos** (por ejemplo, un kit).
4. Pulsa **"Guardar agrupación"**.

<Captura web src="/img/plataforma-web/12-nueva-agrupacion.png" alt="Formulario de nueva unidad de agrupación" pie="Ejemplo: caja 1111 = 6 × masilla aluminio 15045" />

Al guardarla se le asigna un **prefijo EPC**. Sus etiquetas se imprimen con ese prefijo + «A» + serial, igual que las de los productos.

## Desactivar

Desmarca **"Activa"** para que sus etiquetas dejen de contarse en la conciliación. El historial se conserva.
