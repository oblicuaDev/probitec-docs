# Usuarios

Listado de las personas con acceso a la plataforma: nombre, correo, rol, bodegas asignadas, estado (Activo/Inactivo) y último acceso. Los 4 roles disponibles y lo que puede hacer cada uno están en [Roles y permisos](/docs/roles-y-permisos).

Incluye filtros rápidos por **Todos / Activos / Inactivos** y un botón **"Nuevo usuario"** con un formulario (nombre, correo, rol).

:::caution Pendiente de conectar
La creación de usuarios, la edición, la asignación de bodegas y la desactivación (los íconos de acción de cada fila) son por ahora una maqueta visual: la tabla sí trae los usuarios reales, pero ninguna de esas acciones queda guardada todavía. No se recomienda presentarlas como funcionales en una demo hasta que se conecte esta parte.
:::
