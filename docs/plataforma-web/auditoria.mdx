# Auditoría

Registro cronológico de acciones sensibles del sistema: conteos recibidos, cierres y descartes de conteos, justificaciones y omisiones (con su comentario), ajustes, traslados, cargas de inventario inicial, unidades de agrupación, sincronizaciones con Siigo y gestión de usuarios.

<Captura web src="/img/plataforma-web/16-auditoria.png" alt="Registro de auditoría" pie="Auditoría" />

Cada evento queda con usuario, acción, detalle, fecha, hora, IP y dispositivo — información clave para trazabilidad ante el cliente o una revisión interna.

:::note
Los selectores de Fecha / Usuario / Acción y el botón "Exportar" de esta pantalla son controles visuales; todavía no filtran ni exportan datos reales.
:::
