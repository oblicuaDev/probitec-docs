# Auditoría

Registro cronológico de acciones sensibles del sistema: cierres de inventario, ajustes manuales, validaciones documentales, conteos recibidos e inicios de sesión.

Cada evento queda con usuario, acción, detalle, fecha, hora, IP y dispositivo — información clave para trazabilidad ante el cliente o una revisión interna.

:::note
Los selectores de Fecha / Usuario / Acción y el botón "Exportar" de esta pantalla son controles visuales; todavía no filtran ni exportan datos reales.
:::
