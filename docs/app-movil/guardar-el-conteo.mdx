# Guardar el conteo

Al pulsar **"Guardar conteo para verificación"**, la app muestra el envío en 4 pasos: **Preparando datos → Enviando → Guardando → Finalizado**.

## Si todo sale bien

Aparece **"Conteo guardado"** con el código asignado por el servidor (por ejemplo `CNT-2026-014`) y el botón **"Ver conteo finalizado"**. Desde ese momento el conteo ya se ve en la plataforma web.

## Si no hay internet o algo falla

Aparece **"Error al guardar el conteo"** con el motivo y el botón **"Reintentar"**.

**El conteo no se pierde.** Queda guardado en el equipo aunque se cierre la app. Cuando vuelva la conexión, pulsa **"Reintentar"** o, desde **Inicio**, **"Enviar ahora"**.

Reintentar es seguro: si el conteo ya había llegado al servidor, no se duplica.

:::note Qué significa "Pendiente"
Guardar el conteo **no lo verifica**, solo lo registra. La comparación contra el inventario esperado ocurre automáticamente en el servidor, y la revisión de diferencias la hace el **Conciliador** en la plataforma web — ver [Flujo de trabajo](/docs/flujo-de-trabajo).
:::
