# Realizar un conteo

Es la pantalla de escaneo, pensada para usarse con una mano mientras se sostiene el TC22.

## El botón central

- **ESCANEAR** (gris/inactivo): pulsar para iniciar. También puede iniciarse con el **gatillo físico** del RFD40.
- **PAUSAR** (activo, color de marca): el conteo está corriendo. Pulsar para pausar.
- **REANUDAR** (pausado, ámbar): estaba pausado, pulsar para seguir contando.

Mientras está activo, un indicador verde/gris junto al nombre de la bodega muestra si el lector está **RFID Activo**, **Pausado** o **Inactivo**.

## Contadores en vivo

- **Etiquetas leídas**: total de lecturas, incluyendo repetidas.
- **Productos únicos**: EPCs distintos detectados (esto es lo que realmente cuenta para el inventario).
- **Duplicados**: lecturas repetidas del mismo EPC (se descartan del conteo único).
- **Lecturas/seg**: velocidad de lectura actual.

Si se leen etiquetas que no pertenecen al inventario esperado (prefijo no válido), se muestran como **"ignoradas"** y no afectan el conteo.

Debajo se ve un listado de las **últimas etiquetas** leídas, más reciente arriba.

## Modo demo

Si el dispositivo no tiene un lector RFD40 conectado (por ejemplo, probando en un teléfono normal o sin el módulo nativo instalado), aparece el aviso **"MODO DEMO · lecturas simuladas"** y la app genera lecturas de prueba automáticamente — útil para practicar el flujo, pero esas lecturas no son reales.

## Finalizar

El botón **"Finalizar conteo"** se habilita en cuanto hay al menos una lectura válida, y lleva a [Detalle y resumen](/docs/app-movil/detalle-y-resumen).
