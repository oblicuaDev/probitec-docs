# Conteo RFID

Es la pantalla de escaneo, pensada para usarse con una mano mientras se sostiene el TC22 con el lector RFD40.

## El botón central

- **ESCANEAR**: pulsa para empezar. También se puede contar con el **gatillo** del RFD40.
- **PAUSAR**: el conteo está corriendo; púlsalo para pausar.
- **REANUDAR** (ámbar): estaba en pausa; púlsalo para seguir.

Junto al nombre de la bodega se ve si el lector está **RFID Activo**, **Pausado** o **Inactivo**. Arriba a la derecha: tiempo transcurrido, usuario y hora de inicio.

## Unidades contadas

El número grande es lo que se compara contra el inventario: **unidades**, no etiquetas.

- Una etiqueta de **producto** suma **1 unidad**.
- Una etiqueta de **caja** (unidad de agrupación, código `AG-…`) suma **las unidades que trae la caja**. Por ejemplo, 3 cajas de POWER PROTECT x6 suman 18.

## Contadores en vivo

- **Etiquetas únicas**: etiquetas distintas detectadas. El lector lee la misma etiqueta muchas veces; cada una cuenta una sola vez.
- **Productos distintos**: cuántos productos diferentes hay entre esas etiquetas.
- **Cajas (agrupaciones)**: cuántas de las etiquetas son de cajas.
- **Duplicados**: lecturas repetidas, descartadas automáticamente.
- **No registradas**: etiquetas que no corresponden a ningún producto ni caja. **No suman** unidades.
- **Lecturas por segundo**: velocidad de lectura en este momento.

:::tip
Etiquetas no registradas
Si aparecen etiquetas no registradas, revisa en el detalle cuáles son antes de enviar. Puede ser una etiqueta ajena que el lector captó cerca o una etiqueta mal impresa.
:::

## Finalizar

**"Finalizar conteo"** se habilita en cuanto hay al menos una etiqueta leída. Al pulsarlo, el conteo **queda guardado en el equipo** y pasa a [Detalle y resumen](/docs/app-movil/detalle-y-resumen).

Si pulsas la flecha de volver (o el botón atrás del equipo) con etiquetas leídas y sin finalizar, la app pregunta **«¿Descartar este conteo?»**: **Seguir contando** te deja en la pantalla; **Descartar** sale y lo leído se pierde.
