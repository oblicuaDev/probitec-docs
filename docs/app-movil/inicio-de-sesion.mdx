# Inicio de sesión

Es la primera pantalla al abrir la app.

- **Usuario** y **Contraseña**: credenciales del operario (correo del tipo `usuario@oblicua.co`).
- **Recordar sesión**: mantiene la sesión iniciada la próxima vez que se abra la app.
- Un aviso en la parte superior indica el estado de conexión:
  - **"Conectado al servidor Oblicua"** (verde): hay conexión real con la base de datos.
  - **"Modo demo (sin servidor)"** (amarillo): la app no tiene credenciales de servidor configuradas y trabaja con datos de ejemplo — útil para pruebas, pero **no debe usarse para contar inventario real**.
- Si el usuario o la contraseña son incorrectos, aparece un mensaje de error debajo del formulario.

Al iniciar sesión correctamente, se entra directo a la pantalla **Inicio** (ver siguiente sección).
