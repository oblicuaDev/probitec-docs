# Inicio de sesión

Es la primera pantalla al abrir la app.

- **Usuario** y **Contraseña**: credenciales del operario (correo del tipo `usuario@oblicua.co`).
- **Recordar sesión**: mantiene la sesión iniciada la próxima vez que se abra la app.
- Si el usuario o la contraseña son incorrectos, aparece un mensaje de error debajo del formulario.
- **"¿Olvidaste tu contraseña?"**: cambia el formulario al modo recuperación — se escribe el correo en el campo **Usuario** y se pulsa **"Enviar enlace de recuperación"**. Si el correo tiene una cuenta asociada, llega un enlace que abre la plataforma web para definir una nueva contraseña. Ver [Roles y permisos](/docs/roles-y-permisos).

Al iniciar sesión correctamente, se entra directo a la pantalla **Inicio** (ver siguiente sección). Lo que puede hacer cada persona en la app depende de su rol — ver [Roles y permisos](/docs/roles-y-permisos).
