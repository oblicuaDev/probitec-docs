# Historial y diferencias

Dos pantallas de solo consulta, accesibles desde la navegación inferior de Inicio.

## Historial

Lista los conteos anteriores del operario, con filtros rápidos: **Todos**, **Pendientes**, **Verificados**, **Diferencias**. Cada tarjeta muestra el código, la bodega, fecha/hora, usuario y cantidad de productos. Si el conteo tiene diferencias, aparece una nota de aviso invitando a revisarlas.

## Diferencias

Muestra las diferencias encontradas en el **conteo más reciente**, ya conciliado por la web:

- Resumen de **Faltantes**, **Sobrantes** y **Pendientes**.
- Listado con producto, tipo, cantidad y estado (Pendiente, Justificada, Ajustada, No justificada).

:::note
Esta pantalla es solo de consulta. La app **no permite justificar ni ajustar diferencias** — esa gestión se hace exclusivamente en la plataforma web, en [Gestión de diferencias](/docs/plataforma-web/gestion-de-diferencias) y [Ajustes de inventario](/docs/plataforma-web/ajustes-de-inventario).
:::
