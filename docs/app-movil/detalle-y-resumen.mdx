# Detalle y resumen del conteo

Antes de enviar, el operario puede revisar exactamente qué se contó.

## Detalle del conteo

- **Por producto**: cada producto leído con su nombre y código de Siigo, el rango de seriales y cuántas etiquetas se leyeron. Si una etiqueta es un empaque, se muestra a cuántas unidades equivale.
- **Por etiqueta**: la lista de cada etiqueta leída.
- **Etiqueta no registrada**: la etiqueta no corresponde a ningún producto ni unidad de agrupación. Se envía igual y en la web aparece como «etiqueta no reconocida».
- El buscador encuentra por nombre, código o etiqueta.

**"Ver resumen del conteo"** avanza a la siguiente pantalla.

## Resumen del conteo

- **Etiquetas únicas leídas**: el número principal.
- **Total leído**, **Etiquetas únicas**, **Productos distintos**, **Duplicados**, **Ignoradas**.
- Tiempo total, usuario, bodega, fecha y hora.
- **"Guardar conteo para verificación"**: envía el conteo al servidor. Continúa en [Guardar el conteo](/docs/app-movil/guardar-el-conteo).
