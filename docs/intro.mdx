# ¿Qué es Oblicua RFID?

Oblicua RFID es la solución de control de inventarios por radiofrecuencia (RFID) de Oblicua. Está compuesta por **dos aplicaciones que trabajan juntas**:

| Aplicación | Dónde corre | Quién la usa | Para qué |
|---|---|---|---|
| **App móvil** | Terminal Zebra TC22 + lector RFD40 (Android) | Operarios de bodega | Contar el inventario físico (RFID, códigos de barras o manual) en unidades y enviarlo a verificación |
| **Plataforma web** | Navegador (escritorio) | Administradores / supervisores / auditores | Conciliar cada conteo contra lo esperado, resolver diferencias y cerrar el inventario |

Ambas comparten la misma base de datos y se conectan al ERP para traer las bodegas disponibles y los documentos (facturas, notas crédito) que sustentan las diferencias encontradas.

## La idea central

La app **no concilia ni decide nada** — solo cuenta y guarda. Todo conteo que llega desde la app queda con estado **Pendiente**. Es en la **plataforma web** donde ese conteo se compara contra el inventario esperado, se investigan las diferencias y finalmente se cierra el inventario.

```
   TC22 (operario)                    Web (administrador)
 ┌────────────────────┐        ┌──────────────────────────────┐
 │ 1. Contar con RFID  │  ───▶  │ 2. Conciliar automáticamente  │
 │    (app móvil)      │        │ 3. Validar / ajustar          │
 └────────────────────┘        │ 4. Cerrar el inventario        │
                                 └──────────────────────────────┘
```

Para el recorrido completo, paso a paso, ve a **[Flujo de trabajo](/docs/flujo-de-trabajo)**. Lo que cada persona puede ver y hacer en ambas aplicaciones depende de su rol — ver **[Roles y permisos](/docs/roles-y-permisos)**.
